# Deployment Instructions

## Vercel
1. Go to the Vercel dashboard and login.
2. Click on the 'New Project' button.
3. Connect your GitHub account and select the repository `Claude-Code-Tests`.
4. Configure the settings and click 'Deploy'.
5. Once deployed, you can access your application via the provided URL.

## Heroku
1. Visit the Heroku dashboard and login.
2. Click on 'New' and select 'Create New App'.
3. Provide a name for your Heroku app and choose a region.
4. Connect to the GitHub repository `Claude-Code-Tests` under the 'Deploy' tab.
5. Configure automatic deploys if needed, or manually deploy from the branch.
6. Once the deployment is complete, access your app via the generated URL.
